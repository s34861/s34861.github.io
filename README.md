# Personal Portfolio

เว็บไซต์ Portfolio แบบ 2 หน้า พร้อม Glassmorphism UI

## โครงสร้าง

- `index.html` — หน้าแนะนำตัว / ประวัติส่วนตัว
- `portfolio.html` — หน้า Portfolio
- `style.css` — ดีไซน์ทั้งหมด
- `script.js` — interaction เล็กน้อย
- `assets/background.jpg` — ใส่ภาพพื้นหลังของคุณ
- `assets/profile.jpg` — ใส่รูปใบหน้าของคุณ

## วิธีใช้งาน

1. ใส่รูปพื้นหลังที่ `assets/background.jpg`
2. ใส่รูปโปรไฟล์ที่ `assets/profile.jpg`
3. แก้ชื่อ, role, ประวัติ และข้อมูลติดต่อใน `index.html`
4. เปิด `index.html` ใน browser

โปรเจกต์นี้เป็น static website จึงนำขึ้น GitHub Pages ได้ง่าย
